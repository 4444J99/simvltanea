# Visual Form Canon placement

SIMVLTANEA is a distinct artwork. Independent Loop Compositor is the reusable
software in this repository; the functional public API is
`independent_loop_compositor`. See [identity migration](../governance/IDENTITY_MIGRATION.md).

```text
PERSONA / VISUAL FORM CANON
        │
        ├── NARCISSUS
        ├── SIMVLTANEA
        ├── Floating Points
        ├── Up the Hill Backwards
        └── other visual works
```

PORTVS remains the portal connecting those works. It is not the owner of this
composition grammar.

Do not import Narcissus SELF/REFLECTION/ECHO language into this repository.
Their artwork metadata and composition decisions remain distinct. Shared
processing capabilities may serve either work without adopting its title.

Ideal form → instantiation → encounter → observation → revised specification:

1. TripTicks (2017) is a historical instantiation.
2. The Portvs N-loop renderer is a later specification of the grammar.
3. Future compositions bind their own source records and may belong to separate
   artwork identities; no SIMVLTANEA identity is inherited from the software.
