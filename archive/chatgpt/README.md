# ChatGPT Lineage & Session Archive

This directory is the dedicated location for uploading and preserving historical transcripts, prompts, and session exports from `chatgpt.app` related to the **TripTicks / Triptych / SIMVLTANEA** visual project lineage.

## Supported Formats

You can upload:
- **Markdown / Text transcripts** (`.md`, `.txt`)
- **Raw JSON / JSONL exports** (`.json`, `.jsonl`)
- **HTML exports** (`.html`)
- **Extracted prompt logs / notes**

## Subdirectories / Organization

- `archive/chatgpt/sessions/`: Full conversation transcripts and session dumps.
- `archive/chatgpt/prompts/`: Specific prompt sequences, authoring notes, or design discussions.
- `archive/chatgpt/extracts/`: Extracted code snippets, layout specifications, or historical schemas.

## Ingestion Notes

Files placed here serve as immutable historical lineage and evidence for the project's evolution.
