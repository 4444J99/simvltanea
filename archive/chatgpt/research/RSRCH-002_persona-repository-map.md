# Persona — GitHub repository research map

**Inspection date:** September 5, 2026.

## Finding

Use twelve repositories as an initial working corpus, with eleven additional research/publishing repositories, two separately bounded partner references, and a metadata-only discovery queue. These are proposed research tiers, not an assertion that every repository is equally important or ready to run.

Repository existence and selected documentation/source trees were inspected through the connected GitHub account. No builds, test suites, renders, deployments or Copilot sessions were executed. No repositories were modified. README claims remain claims until checked against current source and execution evidence.

## Existing coordination home

The visual-form research already has a home in `organvm/portvs/incubator/triptych-video-canon/`. Its Visual Form Canon explicitly leaves final implementation ownership unresolved and prohibits adjacent-repository mutations during that incubation pass. Portvs is public: sensitive source receipts must not be committed into the public research record.

This is a starting point for audiovisual lineage research, not a claim that all persona/public-life governance already belongs in Portvs.

## Long-range research strands

**Artistic lineage:** connect original works, remakes, selectors, films and browser editions through explicit evidence rather than title similarity. Preserve dated versions and missing-source gaps.

**Shared formal structures:** compare source selection, panels, spatial layers, timing, seed/randomness, textual granularity, modulation and state transitions. A common vocabulary does not require a shared codebase.

**Performance and publication:** distinguish a living instrument from a captured film, installation, stream, podcast or platform-native excerpt. Each output needs its own runtime and approval evidence.

**Voice and audiences:** study the actual creator corpus and preserve the distinction between public life, artistic work, professional presentation and partner/client products.

## Unresolved mappings

The Triptych directory is verified. Its exact lineage to The First Circle and the current three-panel selector still needs file-level reconciliation. A dedicated repository or exact source-file mapping for Floating Points and Up the Hill Backwards was not established in this audit. Their absence from this map is not evidence that the original work is absent.

The inspected Triptych posting packet names local Mac media paths. Those names do not establish that a cloud agent can access the files. Media recovery and remote locators must be checked before a faithful render is promised.

## Copilot execution guidance

Start with the accompanying research-only prompt in GitHub.com's cloud-agent interface. Keep one repository per task and carry forward compact, source-linked findings; do not repeatedly load the entire corpus.

GitHub's current individual-plan documentation says included AI credits reset on the first day of each calendar month at 00:00 UTC and do not roll over. Usage depends on the model and tokens. Cloud-agent work also consumes Actions minutes. The user's actual balance, enabled repositories and Actions availability were not inspected.

The cloud agent defaults to context in its selected repository and can modify only that repository in a run. Broader reading requires appropriate configuration and authorization; this ChatGPT connector's access does not establish Copilot's access.

Keep the first task research-only. Subsequent code work should be a separately scoped branch/PR in the component's actual owner, with an acceptance test and retained publication approval.
